# 내 교육학점 계산기

직원이 **직급**과 **부재 기간**(휴직·파견 등)을 입력하면, 선택한 학점평가 연도의
**목표 교육학점 · 남은 학점 · 계산 근거**를 바로 확인할 수 있는 웹 계산기입니다.

지금까지는 직원이 교육담당자에게 문의하고, 담당자가 엑셀로 일할 계산해 회신해야 했습니다.
이 계산기는 담당자 엑셀과 **똑같은 계산 규칙**을 코드로 옮겨, 묻지 않고도 언제든 직접 확인할 수 있게 합니다.

## 주요 기능

- **목표 학점 계산** — 직급별 기준학점(3급 4 · 4급 5 · 5급 6 · 6급 6)에서 부재 기간만큼 일할 계산한 학점을 뺍니다.
- **남은 학점과 들어야 할 학점** — 이수한 학점을 넣으면 남은 학점과, 0.5학점 단위로 올림한 "들어야 할 교육 학점"을 보여줍니다.
- **계산 근거 표시** — `인정 학점 4학점 × 252일/365일 = 2.8학점 → 목표 학점 4 − 2.8 = 1.2학점`처럼 식으로 보여줍니다.
- **부재 기간 여러 건** — 사유 10가지, 복직 예정일(미래 날짜)로 미리 계산, 신규채용은 입사일만 입력, 겹치는 날은 한 번만 계산합니다.
- **결과 복사 · 계산 규정 안내** — 메신저에 붙여 넣기 쉬운 결과 복사, 접이식 규정 요약.

## 계산 규칙 요약

| 항목 | 규칙 |
|---|---|
| 계산 연도 N | (N−1)년 12월 1일 ~ N년 11월 30일 (학점평가 종료일 11/30) |
| 부재 일수 | 시작일 ~ 복직일 전날, 계산 연도 밖의 날은 제외 |
| 1년 일수 | 365일 (계산 연도 안에 2월 29일이 있으면 366일) |
| 건별 인정 학점 | `ROUND(부재 일수 ÷ 1년 일수 × 기준학점, 1)`, 건마다 반올림 후 합산 |
| 목표 학점 | 기준학점 − 인정 학점 합계 |
| 들어야 할 학점 | (목표 − 이수)를 0.5 단위로 올림, 0보다 작으면 "달성 완료" |

검증 사례: 3급, 2025-03-24 ~ 2025-11-30(252일) → 인정 2.8학점, 목표 1.2학점 (담당자 엑셀과 일치)

## 개인정보

- 이름·사번·연락처는 입력받지 않습니다.
- 모든 계산은 **사용자의 브라우저 안에서만** 하며, 입력값을 서버로 보내거나 저장하지 않습니다.
- 결과는 참고용이며, 정확한 값은 교육담당자를 통해 확인해 주세요.

## 기술 스택

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Vitest · Vercel 배포

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:3000)
npm test         # 계산 규칙 자동 테스트
npm run build    # 배포용 빌드
```

## 폴더 구조

```
app/              페이지 뼈대 (layout, page, globals.css)
components/credit/ 입력 양식·결과 카드 등 화면 컴포넌트
lib/credit/       계산 엔진 (날짜, 부재 기간, 학점 계산, 근거 문장, 입력 검사) + 테스트
```

## 이미지 출처

머리글의 캠코 로고와 마스코트 키우미는 한국자산관리공사(캠코) 누리집(kamco.or.kr)의 이미지이며 저작권은 캠코에 있습니다. 이 계산기는 직원이 참고용으로 만든 비공식 도구로, 캠코의 공식 서비스가 아닙니다.
